Added simple climate model running with FaIR v1.6.2.1 using the AR6 WG3 probabilistic configuration, see [gcages.scm_running.fair.FairSCMRunner][].
FaIR is an optional dependency, see [gcages.scm_running.fair.check_fair_version][] for the precise commit it is pinned to.
Historical emissions can optionally be prepended to the scenarios, see [gcages.scm_running.fair.add_historical_emissions][].
Added a regression test showing that FaIR reproduces AR6's published FaIR results.
